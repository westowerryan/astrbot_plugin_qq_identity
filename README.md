# 只通过QQ号认人

群里那帮人改名片、自称是谁都是戏，模型不能跟着信。
本插件让你的AstrBot认人只认 QQ 号，谁是谁全靠**后台设置里那张 QQ号-名字 两列映射表**，**群名片一概不看**。

## 两列分开改

后台插件设置里 `qq_names` 是一张两列表：
- 点右上角「添加条目」加一行
- **QQ号** 一列、**名字** 一列，各自独立输入框，分开填分开改
- 一个 QQ 号就一行，想挂多个名字，名字栏里用逗号隔开，如 `小张，老张,张哥，张总`
- 改完保存，机器人立刻按新表认人

不用任何指令编辑，全在后台设置里点。

## 只读指令（看一眼用）

| 指令 | 作用 |
| --- | --- |
| `/认人` | 看机器人现在怎么认你 |
| `/名册` | 打印 QQ-名字映射表（两列，多名字用、连） |

## 数据

映射表存在插件配置里（`data/config/astrbot_plugin_qq_identity_config.json` 的 `qq_names`，template_list 结构）。一个 QQ 号一个条目，多个名字就在那个条目的名字栏里逗号隔开。
